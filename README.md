# 📊 Análise Estatística de Missões Espaciais com Python

> Projeto desenvolvido para a **Global Solution 1** da disciplina **Modelagem Linear para Aprendizado de Máquina** da **FIAP**, aplicando conceitos de Estatística Descritiva, Python e Visualização de Dados para analisar um conjunto de missões espaciais.

---

## 📚 Sobre o Projeto

Este projeto tem como objetivo realizar uma análise estatística de um conjunto de dados de missões espaciais, utilizando Python para organizar, processar e interpretar informações.

Foram desenvolvidas tabelas de distribuição de frequências, gráficos estatísticos e análises univariadas, permitindo compreender padrões relacionados à duração das missões, tamanho das tripulações e tipos de missões realizadas.

A proposta busca aproximar conceitos acadêmicos da aplicação prática da Ciência de Dados no contexto da exploração espacial.

---

## 🎯 Objetivos

- Construir tabelas de distribuição de frequências;
- Aplicar Estatística Descritiva em dados reais;
- Desenvolver gráficos para interpretação visual dos dados;
- Calcular medidas de tendência central;
- Calcular medidas de dispersão;
- Calcular quartis;
- Interpretar os resultados obtidos;
- Aplicar Python na análise de dados.

## 💡 Principais Resultados

### 🚀 Duração das Missões

- Média de aproximadamente **15,74 anos**
- Missões variam entre **1,4 e 29,5 anos**
- Alta variabilidade entre os projetos analisados

### 👨‍🚀 Tamanho das Tripulações

- Média próxima de **50 tripulantes**
- Valores entre **1 e 99 integrantes**
- Grande diversidade na composição das equipes

### 🌌 Tipo de Missão

A categoria mais frequente foi:

- 🔬 Research (Pesquisa)

Representando aproximadamente **26,4%** da base de dados.

---

## 📈 Insights

A análise dos dados permitiu observar que:

- Existe grande diversidade entre as missões espaciais.
- Missões de longa duração representam uma parcela significativa da base.
- O tamanho das tripulações varia consideravelmente conforme o objetivo da missão.
- As categorias de missão apresentam distribuição bastante equilibrada.
- Técnicas estatísticas facilitam a identificação de padrões importantes para planejamento e tomada de decisão.
